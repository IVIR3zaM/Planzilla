# N08 install (vendoring, --version)
Do: Implement `install`, which vendors a pinned Planzilla into a consuming repo so it works on any machine and in
cloud sessions with only `python3` (req 1), and upgrades by re-running with a newer version.
Context: Spec `docs/FORMAT.md` §9, §11. D14 layout: `.planzilla/` (VERSION, `plz` launcher that runs the vendored
package with `python3`, `lib/planzilla/` package copy, `roles/`, `templates/`), `.claude/skills/plz-new-plan` and
`plz-run-plan`, `.claude/agents/plz-planner|plz-executor|plz-verifier|plz-visual`, `.agents/skills/plz-*` copies,
and an AGENTS.md block between the §11 markers (created if AGENTS.md is missing, replaced in place if present).
Idempotent; touches only its own files; never `.plan/`; removes vendored files the new version no longer ships.
D25: under `.claude/` and `.agents/` it writes, replaces and removes only `plz-*` paths; it never edits or deletes
other files there, e.g. this repo's bootstrap `.claude/skills/{new-plan,run-plan}`, `.claude/agents/{planner,
executor,verifier}.md`.
Source = the running package and its `kit/` (importlib.resources). D15 `--version vX` downloads the GitHub tag
archive `IVIR3zaM/Planzilla` via urllib, extracts it to a temp dir and installs from that tree; the archive URL
is a parameter so tests pass a `file://` fixture archive (no network in tests). `--target` defaults to cwd.
Kit files are placeholders until N09/N10 fill them; tests use a tmp fake kit tree for layout, plus one test that
every file in the real packaged kit lands at a §11 target.
Read: `docs/FORMAT.md` §9, §11, `src/planzilla/commands/install.py` (stub contract), `src/planzilla/kit/` (names only)
Write: `src/planzilla/commands/install.py`, `tests/commands/test_install.py`, `tests/fixtures/install/**`
Test first: `tests/commands/test_install.py`: installing into an empty tmp repo creates exactly the §11 file set and
`.planzilla/VERSION` holds the package version.
Done when:
- C1 [cmd] `uv run pytest -q tests/commands/test_install.py`
- C2 [review] a second install changes no byte (idempotence test); an install over an older vendored copy removes a
  file the new kit dropped and keeps every non-Planzilla file, including AGENTS.md text outside the markers
- C3 [review] a test runs the vendored `.planzilla/plz --help` with `python3` and a clean env (no PYTHONPATH, cwd =
  target) and it exits 0
- C4 [review] `--version` test installs from a local `file://` tar.gz fixture and writes that version to VERSION;
  a bad URL exits with the §9 code and leaves the target unchanged
- C5 [review] nothing is written under `.plan/` or outside the §11 paths (test snapshots the tree)
- C6 [review] a test pre-creates `.claude/skills/new-plan/SKILL.md`, `.claude/skills/run-plan/SKILL.md` and
  `.claude/agents/{planner,executor,verifier}.md`; they are byte-identical after install and after upgrade (D25)
- C7 [cmd] `uv run ruff check . && uv run ruff format --check . && uv run pytest -q`
