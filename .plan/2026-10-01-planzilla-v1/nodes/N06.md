# N06 brief, log, check commands
Do: Implement the three per-node commands agents call: `brief` prints what an executor or verifier needs, `log`
appends run history, `check` runs a node's `[cmd]` criteria with no model.
Context: Spec `docs/FORMAT.md` §6, §7, §9, §13. `brief <node>` prints the node's brief (L: `nodes/<id>.md`; S/M:
its `## N01` section) and, when the node is on a retry, the last verify findings from its log; on a §13 rerun it
adds the partial-edits notice (D18). The verifier is cold: §9 defines how it gets the brief without findings.
`log <node> ...` appends to `log/<id>.md` (L) or the plan's `## Log` section (S/M) exactly per §7, never editing
earlier entries. `check <node>` runs each `[cmd]` criterion via the shell from the repo root, pass = exit 0 (D11),
prints the §9 result line, and stores output under `runs/<id>/` as §7 says. Use `plan.py` from N04
(`load_plan`, `load_brief`, `node_paths`). Lessons: L1 history only in logs; L4 verifier judges criteria only.
Read: `docs/FORMAT.md` §6, §7, §9, §13, `src/planzilla/plan.py`, `src/planzilla/commands/brief.py` (stub contract),
`tests/fixtures/plans/`
Write: `src/planzilla/commands/brief.py`, `src/planzilla/commands/log.py`, `src/planzilla/commands/check.py`,
`tests/commands/test_brief.py`, `tests/commands/test_log.py`, `tests/commands/test_check.py`,
`tests/fixtures/check/**`
Test first: `tests/commands/test_check.py`: a node with one passing and one failing `[cmd]` criterion prints the §9
FAIL line naming only the failing criterion and exits non-zero.
Done when:
- C1 [cmd] `uv run pytest -q tests/commands/test_brief.py tests/commands/test_log.py tests/commands/test_check.py`
- C2 [review] `brief` tests for both formats: first try (brief only), retry (brief + last findings only, not older
  ones), rerun notice, and the cold verifier variant without findings
- C3 [review] `log` tests: append to an L log and to an S/M `## Log` section; existing bytes unchanged (prefix
  comparison); entry format matches §7
- C4 [review] `check` tests: all-pass, one-fail, node with no `[cmd]` criteria, command output saved per §7, and
  output lines match §9 byte for byte
- C5 [review] `check` runs commands with cwd = repo root and a timeout; no criterion text is evaluated other than
  the backticked command
- C6 [cmd] `uv run ruff check . && uv run ruff format --check . && uv run pytest -q`
