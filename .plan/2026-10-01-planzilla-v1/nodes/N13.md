# N13 serve: live view
Do: Implement `serve`, a local live web page of a plan's graph that refreshes itself, built on the same data as
`status` (N12) so the two never disagree.
Context: Spec `docs/FORMAT.md` §9, §12. D20 stdlib `http.server` bound to 127.0.0.1, port 8765 (`--port`), one
self-contained HTML page (inline CSS/JS, no CDN) polling a JSON endpoint every 2 s; light and dark via
`prefers-color-scheme`; usable at 375px width. Req 13: nodes grouped by wave showing status (planning, replanning,
executing, verifying, done, blocked), try/replan counts, last log line, elapsed. The JSON body is exactly the §12
live-view schema, produced from `report.py` (N12) on every request (reads files + git log; no cache, no state file).
Read-only: the server never writes. The page lives as package data so `install` vendors it with the package.
Read: `docs/FORMAT.md` §9, §12, `src/planzilla/report.py`, `src/planzilla/commands/status.py`,
`src/planzilla/commands/serve.py` (stub contract)
Write: `src/planzilla/commands/serve.py`, `src/planzilla/web/**`, `tests/commands/test_serve.py`
Test first: `tests/commands/test_serve.py`: start the server on a free port in a thread against an L fixture;
GET the JSON endpoint returns the §12 schema with the fixture's nodes; GET `/` returns HTML.
Done when:
- C1 [cmd] `uv run pytest -q tests/commands/test_serve.py`
- C2 [smoke] `uv run planzilla serve --port 8799` on `.plan/2026-10-01-planzilla-v1` answers `curl -s
  127.0.0.1:8799/` with the page and the JSON endpoint with every node N01-N17; it listens on 127.0.0.1 only
- C3 [review] the page has no external URL (`grep -E 'https?://'` on `src/planzilla/web/` finds none), polls every
  2 s, groups by wave, shows the six status names, and has light and dark color schemes
- C4 [review] a JSON change between polls (status flipped in the fixture) is visible on the next GET (test)
- C5 [review] serve never writes files; unknown paths return 404
- C6 [cmd] `uv run ruff check . && uv run ruff format --check . && uv run pytest -q`
